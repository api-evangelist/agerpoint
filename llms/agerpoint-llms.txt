# Agerpoint

> Agerpoint is a spatial-intelligence company in Research Triangle Park, North Carolina that turns
> real-world field data into AI-derived crop, tree and land measurements. Its Capture mobile app builds
> full-resolution 3D digital twins of plants from a smartphone video; Agerpoint Cloud fuses those
> captures with LiDAR, drone imagery, satellite data, sensors and equipment telemetry to derive plant
> metrics for yield estimation, disease detection, carbon sequestration and biodiversity assessment.

## Status of the API for agents

Agerpoint runs a real, live REST API at https://cloudapi.agerpoint.com, but it is a **customer-only
surface**. As of 2026-09-12 there is:

- no public developer portal, API reference, or getting-started guide
- no OpenAPI, Swagger, GraphQL SDL, WSDL, AsyncAPI or Postman collection at any public URL
- no MCP server and no A2A agent card
- no SDK on npm, PyPI, NuGet, Maven Central or anywhere else
- no published pricing, rate limits, status page, changelog, or deprecation policy

An agent cannot integrate with Agerpoint from public information. Access requires a commercial
relationship: https://www.agerpoint.com/contact

This file is generated by API Evangelist from third-party observation. It is not published by Agerpoint.

## What is actually reachable

- [Agerpoint Cloud API](https://cloudapi.agerpoint.com): Live REST/JSON API on ASP.NET Core (Kestrel).
  Every operation requires an OAuth 2.0 bearer token; unauthenticated requests answer HTTP 401 with
  `WWW-Authenticate: Bearer`. No contract is published.
- [Auth0 OIDC discovery](https://agerpoint.us.auth0.com/.well-known/openid-configuration): The one
  machine-readable document Agerpoint's stack serves anonymously. Authorization server for the
  `https://cloudapi.agerpoint.com` audience. Supports authorization_code + PKCE, client_credentials,
  refresh_token, device_code, token-exchange, DPoP and dynamic client registration.
- [JWKS](https://agerpoint.us.auth0.com/.well-known/jwks.json): Signing keys for the API's bearer tokens.
- [Tile service health](https://tiles.agerpoint.com/healthz): Reports TiTiler 1.2.0 / rasterio 1.5.0 /
  GDAL 3.12.1 / PROJ 9.7.1. The tile surface itself is RBAC-gated (HTTP 403).

## Observed resource families (not a contract)

Read from the first-party console bundle at https://cloud.agerpoint.com, not from documentation:
Captures, CaptureImages, CaptureVideos, CaptureAudios, CaptureImageTags, CaptureExtractionJobs,
Projects, Collections, Layers, LayerGroups, Geometries, GeometryCollections, ImageMosaics, GSplatModels,
Uploads, UploadFiles, AnalyticRequests, CustomerAnalytics, MediaAnalysisPipelines, PipelineJobs, Plans,
Customers, Roles, ResourceUsage, and custom-attribute collections for most of the above.

Conventions observed: pagination as `/api/{Resource}/skip/{n}/take/{n}`; tenant-shared projections via a
`/shared` suffix; long-running work submitted as jobs and polled at `/{id}/status`; no idempotency key;
no versioning; no rate-limit headers. An OGC WMS endpoint exists at
`https://cloudapi.agerpoint.com/api/maps/wms` but GetCapabilities returns HTTP 401.

Geospatial formats in use: GeoJSON (RFC 7946), KML/KMZ, CSV/TSV, LAZ point clouds, PLY meshes, and Cloud
Optimized GeoTIFF rasters served over the OGC WebMercatorQuad tile matrix set. Coordinates in EPSG:4326,
rendered in EPSG:3857.
